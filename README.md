## HuaaApp
Alzheimer's Awareness and Support App Built with MIT App Inventor. Developed by Annie Bao and Isaac Zhang in 2024.

Note: Since it is built in MIT App Inventor, raw code cannot be shown on github.

## Presentation/Demo of App: 
https://drive.google.com/file/d/1zWxCht0D0DyrFJ5udwLRlLAu13YYlKgy/view?usp=sharing 
(Skip to 1:11 to see app content)

## Features
- Daily mood test and medicine tracker
- Physical and mental exercise recommenders
- Memories recorder
- Chatbot + Other relevant information
- Finding home with simple directions
- Family Chat

## Technologies Used
- MIT App Inventor
- Chatbot API
- Text to speech and speech input
- GPS Location
- Computer Vision Through Posenet Extension
- Cloud Database
